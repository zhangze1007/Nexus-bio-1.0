# External Review Templates

This directory contains templates for a future external reviewer pilot. It does not contain completed review data.

- `reviewer-responses.template.json`: empty response template for one anonymous reviewer.
- `adversarial-cases.json`: empty adversarial bypass log template.
- `disagreement-cases.json`: empty disagreement case log template.
- `pilot-summary.template.json`: empty pilot summary template.

All files are marked `template-not-yet-run` or `not-yet-run`. Do not treat them as review outcomes, agreement rates, bypass rates, or validation evidence.
