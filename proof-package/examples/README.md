# Showcase Examples

This directory contains the narrow Step 16 trust-gated showcase examples:

- `safe-pathway.json`: partial PATHD/FBASim path with provenance and expected `ok` decisions on allowed surfaces.
- `blocked-cethx-claim.json`: demo CETHX protocol-like claim blocked by the trust runtime.
- `showcase-one-page.md`, `showcase-script.md`, and `showcase-selection.md`: reviewer-facing notes copied from `docs/`.

The showcase demonstrates trust-boundary behavior. It is not biological optimization proof, wet-lab validation, or scientific model validation.
