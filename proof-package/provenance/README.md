# Provenance Examples

This directory contains SBOL/PROV-linked examples and the provenance middleware note:

- `example-provenance-bundle.json`
- `example-sbol-artifact.json`
- `sbol-prov-linked-README.md`
- `PROVENANCE_MIDDLEWARE.md`

A provenance bundle links evidence, tool-run activity, and generated artifacts so a reviewer can inspect why an output is traceable. These examples support local replayability and vocabulary alignment.

They are not full validator-backed SBOL or PROV-DM compliance fixtures, and they do not establish wet-lab or external validation.
