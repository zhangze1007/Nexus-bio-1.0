# Inventory Management

The Inventory Management tool provides lab materials and reagent tracking for synthetic biology research.

## What It Does

The Inventory Management system tracks lab materials, reagents, plasmids, strains, and other resources used in synthetic biology experiments. It integrates with the workbench to maintain a centralized inventory across team members.

## Key Features

- **Material Tracking** — Track reagents, chemicals, and consumables
- **Plasmid Registry** — Manage plasmid collections with metadata
- **Strain Management** — Track bacterial and yeast strains
- **Stock Alerts** — Notifications when supplies run low
- **Barcode Support** — Scan and track materials with barcodes
- **Team Collaboration** — Shared inventory across team members

## How to Use It

1. Navigate to `/tools/inventory` in the Nexus-Bio IDE
2. Browse the inventory by category (reagents, plasmids, strains)
3. Add new items or update existing stock levels
4. Set up alerts for low-stock items
5. Generate reports for grant applications or audits

## Inventory Categories

### Reagents
- Chemicals and solvents
- Enzymes and buffers
- Media components
- Antibiotics

### Plasmids
- Backbone vectors
- Expression constructs
- Reporter plasmids
- CRISPR guides

### Strains
- E. coli strains
- Yeast strains
- Cell lines
- Competent cells

## Integration with Workbench

The Inventory Management tool connects to the Nexus-Bio workbench:

- **Experiment Ledger** — Track which materials were used in each experiment
- **Decision Trace** — Record why specific materials were selected
- **Audit Trail** — Maintain a complete history of inventory changes

## Example Workflow

1. Add a new plasmid to the registry with sequence and metadata
2. Record the plasmid used in a transformation experiment
3. Update stock levels after the experiment
4. Set up alerts for when the plasmid stock runs low
5. Generate a report of all materials used in a project
