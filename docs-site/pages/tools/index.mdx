# Tool Overview

Nexus-Bio provides 14 integrated tools organized across the 4-stage synthetic biology research cycle.

## Stage 1: Design & Discovery

| Tool | Route | Description |
|------|-------|-------------|
| [Pathway Designer](/tools/pathd) | `/tools/pathd` | 3D metabolic pathway lab with DBTL integration |
| NEXAI | `/tools/nexai` | AI research agent with citation network and Socratic questioning |

## Stage 2: Simulation & Optimization

| Tool | Route | Description |
|------|-------|-------------|
| [FBA Simulator](/tools/fbasim) | `/tools/fbasim` | Flux balance analysis with single and community FBA |
| CETHX | `/tools/cethx` | Cell thermodynamics with waterfall ΔG cascade |
| ProEvol | `/tools/proevol` | Protein evolution with fitness landscape heatmap |
| CATDES | `/tools/catdes` | Enzyme design with binding affinity and Pareto front |

## Stage 3: Chassis Engineering

| Tool | Route | Description |
|------|-------|-------------|
| GenMIM | `/tools/genmim` | Gene minimization with CRISPRi knockdown scheduling |
| GECAIR | `/tools/gecair` | Gene circuit reasoner with Hill function modeling |
| DynCon | `/tools/dyncon` | Dynamic control with bioreactor simulation |

## Stage 4: Test & Iterate

| Tool | Route | Description |
|------|-------|-------------|
| DBTLflow | `/tools/dbtlflow` | DBTL cycle tracker with iteration waterfall |
| CellFree | `/tools/cellfree` | Cell-free system simulation |
| MultiO | `/tools/multio` | Multi-omics integration with VAE/UMAP |
| ScSpatial | `/tools/scspatial` | Single-cell spatial with hexagonal spot grid |

## Additional Tools

| Tool | Route | Description |
|------|-------|-------------|
| [Sequence Editor](/tools/sequence) | `/tools/sequence` | DNA/RNA sequence editing and analysis |
| [Inventory Management](/tools/inventory) | `/tools/inventory` | Lab materials and reagent tracking |
