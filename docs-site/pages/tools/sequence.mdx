# Sequence Editor

The Sequence Editor provides DNA/RNA sequence editing and analysis capabilities within the Nexus-Bio platform.

## What It Does

The Sequence Editor enables researchers to design, edit, and analyze DNA and RNA sequences for synthetic biology applications. It integrates with other Nexus-Bio tools for a seamless workflow from sequence design to pathway implementation.

## Key Features

- **Sequence Editing** — Interactive editor for DNA/RNA sequences
- **Codon Optimization** — Optimize codon usage for target organisms
- **Restriction Site Analysis** — Identify and annotate restriction enzyme sites
- **Primer Design** — Design PCR primers for sequence amplification
- **SBOL Integration** — Export sequences in SBOL format

## How to Use It

1. Navigate to `/tools/sequence` in the Nexus-Bio IDE
2. Enter or paste a DNA/RNA sequence
3. Use the analysis tools to examine the sequence
4. Design primers or optimize codons as needed
5. Export the final sequence for synthesis

## Integration with Other Tools

The Sequence Editor works with:

- **Pathway Designer** — Design gene sequences for pathway components
- **Gene Circuit Reasoner (GECAIR)** — Create sequences for genetic circuits
- **Gene Minimization (GenMIM)** — Optimize sequences for minimal genomes
- **DBTLflow** — Track sequence design iterations

## Supported Formats

- FASTA
- GenBank
- SBOL (Synthetic Biology Open Language)
- Plain text

## Example Workflow

1. Design a gene sequence for a new enzyme
2. Optimize codons for E. coli expression
3. Add restriction sites for cloning
4. Design primers for PCR amplification
5. Export in SBOL format for synthesis ordering
