# Authentication

## Overview

Nexus-Bio uses OAuth 2.0 for user authentication and API access. The platform supports GitHub and Google as identity providers.

## User Authentication

### Sign In

1. Visit [nexus-bio-1-0.vercel.app](https://nexus-bio-1-0.vercel.app)
2. Click "Sign In" in the top navigation
3. Select GitHub or Google as your identity provider
4. Complete the OAuth flow
5. You will be redirected back to Nexus-Bio with an active session

### Session Management

- Sessions are managed via secure HTTP-only cookies
- Sessions expire after 7 days of inactivity
- Active sessions can be viewed and revoked in the user settings

## API Authentication

### API Keys

For programmatic access to Nexus-Bio APIs, you need an API key:

1. Sign in to your Nexus-Bio account
2. Navigate to Settings → API Keys
3. Click "Generate New API Key"
4. Copy the key (it will only be shown once)

### Using API Keys

Include the API key in the `Authorization` header:

```bash
curl -X POST https://nexus-bio-1-0.vercel.app/api/analyze \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query": "design artemisinin pathway"}'
```

### API Key Scopes

API keys can be configured with the following scopes:

| Scope | Description |
|-------|-------------|
| `read` | Read access to projects and data |
| `write` | Write access to projects and data |
| `analyze` | Access to AI analysis endpoints |
| `admin` | Full administrative access |

## Environment Variables

For server-side API access, configure the following environment variables:

```env
GROQ_API_KEY=your_groq_key
GEMINI_API_KEY=your_gemini_key
```

These are used by the AI endpoint for Groq and Gemini API access.

## Security Best Practices

1. **Never expose API keys in client-side code** — Use server-side API routes
2. **Rotate keys regularly** — Generate new keys every 90 days
3. **Use minimal scopes** — Only grant the permissions needed
4. **Monitor usage** — Review API usage logs for suspicious activity
5. **Revoke compromised keys** — Immediately revoke any keys that may have been exposed

## Error Codes

| Code | Description |
|------|-------------|
| `401` | Unauthorized — Invalid or missing authentication |
| `403` | Forbidden — Insufficient permissions for the requested resource |
| `429` | Too Many Requests — Rate limit exceeded |
| `503` | Service Unavailable — AI providers are down |
