# LearnedDeltaPack Examples

These examples are fictional trust-runtime records. They are not wet-lab validation evidence and do not claim scientific validation.

- `pending-conservative.json`: valid typed record waiting for review; not applicable to seed builders.
- `approved-restorative.json`: valid approved record with one explicit prior delta.
- `rejected-aggressive.json`: valid historical record that must not apply.
- `invalid-missing-experiment-source.json`: invalid because `sourceExperimentRecordIds` is empty.

Only approved, valid packs with experiment source ids may be applied by the current seed-builder boundary.
